# GUARDIAN AI: MASTER MANIFESTO & FEATURE SPEC

## 1. THE MISSION
"To provide unblinking protection for the vulnerable and undeniable truth for the innocent. We build the world's first 'Privacy-Correct' security ecosystem—delivering total visibility where it’s needed, and absolute dignity where it’s demanded."

## 2. CORE ENGINEERING PRINCIPLES
1.  **Truth Above All (The Black Box):** The integrity of the log is absolute. Video can be deleted; the "System Audit Log" cannot.
2.  **Privacy by Zone:**
    * **Public/Entry:** Facial Recognition ON (Identify Friend vs. Foe).
    * **Private (Bath/Bed):** Facial Recognition HARD BLOCKED. Skeletal/LiDAR only.
3.  **Active Defense (Pre-Event):** We do not wait for the crime. We detect *intent* (Pre-Event Telemetry).
4.  **No Compromise:** If a feature cannot be executed to the cutting edge, it does not ship.

## 3. MASTER FEATURE LIST

### A. THE "HOME" SYSTEM (Residential)
* **The Integrity Monitor ("Gaslight Protection"):**
    * *Function:* Logs every camera disconnect, WiFi drop, or power cycle to an immutable ledger.
    * *Use Case:* Proves if a spouse or intruder disabled security to hide activity.
* **Perimeter Continuity ("The Cat Tracker"):**
    * *Function:* Uses multi-camera hand-off to track objects across non-overlapping zones.
    * *Use Case:* "Hey Guardian, where's the cat?" -> "Last seen heading North to the neighbor's yard."
* **The Fatal Error Interlock (Pool Safety):**
    * *Logic:* IF `Zone == Pool` AND `Gate == Open` AND `Subject == Child` -> Trigger Siren + Lock Back Door.
* **Privacy Curtain (Bathroom Mode):**
    * *Function:* Hardware-level terminate of RGB video streams in private zones; keeps LiDAR/Skeleton active for fall detection only.

### B. THE "TRAVEL" APP (Personal Protection)
* **The "Dead Man's Switch" (Check-In):**
    * *Function:* If user doesn't check in by a set time, encrypted evidence (location/audio) is auto-sent to emergency contacts.
* **Hotel Room Sweep:**
    * *Function:* Uses phone Lidar/Magnetometer to detect hidden lenses or rogue WiFi signals in a hotel room.

### C. THE BUSINESS SYSTEM (Commercial)
* **Letterhead Generator:**
    * *Function:* Auto-generates formal notices/invoices.
* **Liability Shielding (Nursing Homes):**
    * *Function:* Skeletal tracking for falls. Prove *exactly* when a patient fell and how long it took staff to respond.
* **Staff Access Security:**
    * *Function:* Facial recognition for authorized zone entry; logs access events for security compliance and unauthorized entry detection.
    * *Use Case:* Verify only authorized personnel enter secure zones (medication storage, patient areas). Detect tailgating or credential sharing.
